台割工房 {VERSION} ― はじめにお読みください
============================================================

生成画像で作るマンガの「台割」（ページの順番・進行・セリフ）を管理する道具です。
いまの台割（v2）を丸ごと置き換える第1段です。


■ 中身
  台割工房.pyw              本体（画面も処理もこの1ファイル）
  台割工房.ico              アイコン（各フォルダの 台割.daiwari の絵にも使います）
  setup.bat                 初回のセットアップ
  uninstall.bat             関連付けとショートカットを外すとき
  update.bat                最新の版にする（git で取ってきたときだけ）
  取扱説明書.pdf            画面写真つきの説明書
  はじめにお読みください.txt  このファイル


■ 入れ方
  1. ZIP を右クリック →「プロパティ」→ 下のほうの「許可する」にチェック → OK
     （ネットから落としたファイルの印を外します。外さないと setup.bat が止められることがあります）
  2. ZIP を展開して、「台割工房」フォルダを好きな場所に置きます
     例：ドキュメント\ツール\台割工房
     ※ あとで置き場所を変えたら、移した先で setup.bat をもう一度実行してください
  3. setup.bat をダブルクリック。管理者の権限は要りません
     ・Python（3.10 以上）と Pillow を確かめ、Pillow が無ければ入れます
     ・「台割.daiwari」をダブルクリックで開けるようにします
     ・フォルダの右クリック「送る」と、デスクトップに「台割工房」を足します
     ・古い「台割を開く.bat」からも開けるよう、中継を置きます


■ 更新のしかた（おすすめ：git で取ってきて、update.bat をダブルクリック）
  初回だけ
    1. Git for Windows を入れる（PowerShell で  winget install --id Git.Git -e  か、
       https://git-scm.com/ のインストーラ）
    2. 置き場所にしたいフォルダでコマンドを1行（例：ドキュメント）
         git clone https://github.com/ikemenngitarisuto-cpu/daiwari-kobo.git
       非公開のリポジトリなので、初回だけブラウザで GitHub へのサインインを求められます。
       2回目からは覚えています。
    3. できた daiwari-kobo\台割工房\setup.bat をダブルクリック
       （ZIP で入れていた分は、もう使いません。関連付けがこちらへ付け替わります）
  更新するとき
    daiwari-kobo\台割工房\update.bat をダブルクリック。最新を取ってきて、版を表示します。
    開いている台割工房の窓は、いったん全部閉じてから開き直してください。
    各画像フォルダの 台割.daiwari と .daiwari は、更新で消えたり変わったりしません。
  ほかのやり方
    ・GitHub Desktop で daiwari-kobo を Clone して、更新は「Fetch origin」→「Pull origin」
    ・ZIP：GitHub の release\台割工房.zip を落とし、「許可する」→ 展開して上書き


■ 使い方
  初めてのフォルダ
    画像フォルダを右クリック →「送る」→「台割工房」
    （Windows 11 は、右クリックのいちばん下の「その他のオプションを表示／確認」の中にあります）
    デスクトップの「台割工房」アイコンにフォルダを落としても同じです。
    フォルダに「台割.daiwari」ができて、専用のウィンドウで開きます。

  2回目から
    フォルダの「台割.daiwari」をダブルクリック。
    フォルダを丸ごと移動・コピー・改名しても、そのまま開けます。

  終わるとき
    ウィンドウを閉じるだけです。入力はその場で保存されています。


■ いまの台割（v2）からの引っ越し
  ・何もしなくて大丈夫です。v2 で使っていたフォルダを開くと、
    .daiwari.json を読んで 台割.daiwari を作ります（元のファイルは .daiwari\backup へ移します）。
  ・ページ順・原画と完成の組・空白・除外・メモを引き継ぎます。
    メモはまず「セリフ」欄に入ります。「」の行とそれ以外をセリフとメモに振り分けるかを、
    画面の上で1回だけ聞きます（振り分けても Ctrl+Z で戻せます）。
  ・「_除外」フォルダがあれば、「未使用」へまとめるかを1回だけ聞きます。
    まとめなくても、隔離した絵として扱います。
  ・各フォルダの古い「台割を開く.bat」は、そのまま使えます（台割工房が開きます）。
  ・v2 の本体（daiwari.py と web フォルダ）は、もう使いません。


■ 困ったとき
  ・何かおかしいときは、そのフォルダの .daiwari\log.txt に記録があります。
  ・同じフォルダを2回開くと、開いている窓が前に出ます。
  ・Edge が見つからないときは、いつものブラウザのタブで開きます。
  ・管理データを戻したいとき：設定 →「バックアップ」から戻せます
    （直近20回分と、日ごとの7日分を .daiwari\backup に残しています）。
  ・画像ファイルを消す機能はありません。「隔離」は「未使用」フォルダへ移すだけです。


■ 動く環境
  Windows 10 / 11、Python 3.10 以上、Pillow、Microsoft Edge（無ければ既定のブラウザ）
